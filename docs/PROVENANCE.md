# Provenance

I built this repository from the reviewed VOLLEY 2026-08-03 working-tree snapshot derived
from base commit `d82877a`. That snapshot contains corrected quadrature, recoil, covariance,
A12 force-plane and A13 internal-momentum work that was not yet committed in the source checkout.
It is therefore defined by the per-file hashes and aggregate SHA-256 in `SOURCE_MANIFEST.json`.

NASA GMAT reproduced and challenged numerical claims; NASA did not validate or endorse VOLLEY.
A9 requires public orbital data and has not been run.
